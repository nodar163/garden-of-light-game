# Сад света / Garden of Light

Уютная игра **«Сад света»: два режима по 250 уровней (всего 500)**, русский и английский интерфейс. «Дорожки света» — соединения, «Цветочный каскад» — цветочное три в ряд. Актуальная браузерная версия: https://nodar163.github.io/garden-of-light-game/ . Нативные APK/EXE пока относятся к раннему прототипу.

## Новый главный экран и сад

Сад теперь занимает весь экран: карточка Джека с целью, одна основная кнопка игры, отдельный выбор режимов. Пять участков одного мира, новые клумбы, ландшафтные группы посадок и предпросмотр восстановления. [Разбор похожих игр и изменения](docs/GARDEN-REDESIGN.md).

## Что уже реализовано

- Отдельный режим «Цветочный каскад»: 250 уровней, обмены, падения, каскады, четыре усилителя и комбинации, цели и роса, бесплатные повторные попытки. См. `docs/FLOWER-CASCADE.md`.
- Объёмные цветы, плавные анимации, тихие повороты дорожек и единая мелодия в меню и игре.

- Повороты дорожек, взаимные соединения, источник и раскрывающиеся растения.
- 250 фиксированных уровней от 3×3 до 7×7; первые три объясняют правила.
- 10 цветовых областей, выбор по 25 уровней. Общий сад Джека с покупками и восстановлением построек — см. `docs/JACK-GARDEN.md`.
- Отмена, перезапуск и бесплатная подсказка в два действия: показать → применить.
- Принимается любое решение, которое освещает все растения.
- Локальное автосохранение с временным файлом и резервной копией.
- Меню, выбор уровней, сад прогресса, настройки, русский и английский языки.
- Собственная векторная графика и синтезированный звук внутри приложения.
- Нет аккаунтов, рекламы, покупок, аналитики и сетевой логики.

## Запуск на этом компьютере

1. Откройте эту папку в **Visual Studio Code** через «Файл → Открыть папку».
2. Откройте терминал VS Code и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools.ps1 run
```

Либо «Терминал → Запустить задачу → Garden: run». Редактор Godot открывается командой `powershell -ExecutionPolicy Bypass -File .\tools.ps1 editor`.

На этом компьютере Godot лежит в `.tools/godot`. Папка `.tools` содержит инструменты, не исходники игры; её не нужно отправлять в Git или включать в приложение.

## Перенос на другой компьютер

- Установите **Godot 4.7.2 standard (не .NET)** и соответствующие export templates **4.7.2.stable**.
- Распакуйте Godot в `.tools/godot` либо задайте переменную `GODOT_BIN` с полным путём к исполняемому файлу.
- Откройте `project.godot` в Godot или выполните `tools.ps1 import` для первого импорта ресурсов.
- Рекомендуемое расширение VS Code: `geequlim.godot-tools`. Для подсказок GDScript редактор Godot должен быть запущен.
- Для APK нужны JDK 17, Android SDK platform 35, platform-tools, build-tools 35.0.1 и дополнительные версии, запрошенные шаблоном Gradle. В Godot укажите пути в Editor Settings → Export → Android.
- Первый Android-экспорт устанавливает стандартный шаблон Godot в `android/build`. Эта сгенерированная папка исключена из Git. После смены версии движка её надо пересоздать из соответствующего шаблона.

Версия проекта зафиксирована в `docs/TOOLCHAIN.md`. Не обновляйте движок или плагины автоматически в середине проверки прототипа.

## Проверки и сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\tools.ps1 test
powershell -ExecutionPolicy Bypass -File .\tools.ps1 ui-test
powershell -ExecutionPolicy Bypass -File .\tools.ps1 apk
```

`test` проверяет правила, решения всех 250 уровней и сохранения. `ui-test` проходит 250 уровней через игровой интерфейс и сохраняет снимки экранов в `artifacts`. Используются отдельные тестовые сохранения, прогресс игрока не изменяется.

APK: `artifacts/garden-of-light-prototype.apk`. Это тестовая сборка, подписанная отладочным ключом; не загружать её как финальный продукт в Google Play. Приложение ориентировано на Android 8+ и архитектуры arm64-v8a/x86_64.

Чтобы попробовать на телефоне, перенесите APK на Android и откройте его, следуя системным шагам установки. Для проверки офлайн-режима выключите сеть до первого запуска. Для компьютера есть отдельный файл `artifacts/garden-of-light.exe` — Godot для его запуска не нужен.

При кириллице в пути задача `apk` создаёт техническую ссылку `%USERPROFILE%/GardenOfLightBuild` на папку проекта. Это та же папка, а не вторая копия. SDK и JDK в настройках Godot тоже должны использовать путь латиницей. Скрипт не заменяет уже существующую ссылку на другой проект.

## Как играть

Нажимайте на дорожки: каждое нажатие поворачивает элемент на 90°. Фонарь и растения неподвижны. Свет проходит только через совпадающие соединения соседних клеток. Когда освещены все растения, уровень завершён. Необязательно использовать все дорожки.

«Подсказка» сначала выделяет элемент; «Применить» устанавливает один вариант его положения. «Отмена» возвращает предыдущее состояние. «Заново» возвращает стартовую расстановку. Цветок в саду выдаётся только один раз за уровень.

При удалении приложения или очистке его данных сохранения могут быть потеряны. Облачной синхронизации нет. История отмены сохраняется только в текущем сеансе уровня.

## Структура

- `scripts/puzzle.gd` — правила без графики.
- `scripts/save_store.gd` — сохранение и восстановление.
- `scripts/main.gd` — экраны и игровая последовательность.
- `scripts/board.gd` — отрисовка сада, дорожек и цветов.
- `scripts/sound.gd` — музыка и звуки.
- `levels/01.json` … `250.json` — подготовленные уровни.
- `tests/` — проверки правил и интерфейса.
- `docs/` — ограничения, тестирование людьми и подготовка выпуска.

`tools_build_assets.py` воспроизводит авторские уровни и синтезированный звук стандартной библиотекой Python. Во время игры Python не нужен. Не запускайте этот скрипт после ручных изменений уровней, если не хотите восстановить исходные варианты.

## iPhone: браузерная версия

Сборка: `./tools.ps1 web` (Godot 4.7.2 + web templates, Python 3).
Готовые файлы находятся в `web-site/dist`. Открывать через HTTP(S), не двойным нажатием HTML.
На iPhone используйте обновлённый Safari (iOS 16.4+); можно добавить страницу на главный экран через меню «Поделиться».
Первое открытие требует интернета. Включён PWA-кэш, но его сохранность и работа без сети на реальном iPhone ещё не проверены. Прогресс хранится в браузере; очистка данных сайта его удаляет.
Это веб-прототип, не приложение App Store. Публикация не означает наличие в поиске Google.

Владелец подтвердил работу прежней версии на GitHub Pages. Результаты проверок текущей версии записываются в `docs/STATUS.md`. Safari на физическом iPhone, звук, сворачивание и автономный запуск требуют отдельной проверки на устройстве.
