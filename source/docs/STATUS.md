- На физическом Android не запускалось: `adb devices` не обнаружил устройств.
- Не проверены реальный авиарежим, системные панели разных телефонов, нагрев и 20-минутная сессия.
- Нет пяти пользовательских сессий; интерес и спокойствие не измерены.
- Уровни 11–30 не создавались: это следующий этап после проверки интереса.
- Нет релизного AAB, публичного размещения или одобрения Google Play.
- Тестовый APK около 155 MiB: стандартный отладочный движок содержит две архитектуры. Оптимизация размера релизной сборки — задача этапа пилота.
- Все 10 начальных уровней содержат по одному растению: это соответствует диапазону 1–2 и позволяет освоить механику без развилок. Внутренняя логика нескольких растений и развилок проверена отдельно.
- История отмены не переживает выход из уровня; сама расстановка сохраняется.
- Общий сад — фиксированная композиция из десяти растений, без редактора строительства.
- В ранних запусках были предупреждения о звуковых ресурсах при завершении; явная остановка проигрывателей устранила их в последнем оконном UI-тесте.

## Исправленные причины ошибок

- Числа из JSON имеют другой числовой тип: повороты нормализованы к целым, включая восстановление.
- Ключ уровня `1.0` не совпадал с `1`: ключи сохранений приведены к целому номеру.
- Повреждённый JSON обрабатывается через возвращаемую ошибку парсера и резервную копию.
- Тест замкнутого контура содержал дополнительный рабочий путь; пример исправлен без изменения корректной логики обхода.
- Для min SDK 26 включена Gradle-сборка и Android-импорт текстур.
- Кириллический SDK-путь заменён технической ссылкой латиницей.

Следующее внешнее действие: установить APK на Android и выполнить `docs/PLAYTEST.md`. До получения этих результатов не отмечать этап Android-проверки или проверку интереса завершёнными.
